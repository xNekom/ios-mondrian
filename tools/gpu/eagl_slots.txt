# The calls CoreAnimation makes through -[EAGLContext getMacroContextPrivate], as offsets into
# the table iOS's own OpenGL ES hands it. tools/gpu/mkeagl.py reads this file and emits
# eagl_gen.h: one forwarder per entry, the table they are placed in, and their names for the log.
#
#   OFFSET  NAME  [hand [MACRO]]     (fourth column: the name mondrian_offsets.h gives the offset;
#                                    mkeagl.py refuses a file where the two disagree)
#
# `hand`: eagl.c defines that entry itself (my_gl<Name>, where it has work to do beyond passing
# the call on). Every other entry gets a generated forwarder, provided a prototype for it is in
# the OpenGL ES headers mkeagl.py parses. An offset NOT listed here is a call that is logged as
# "CALLED AND NOT THERE" with its offset, which is how the rest of this file is found.
#
# The 30 entries below are the ones eagl.c names. CoreAnimation uses more than a hundred others
# -- glEnable, glBlendFunc, glViewport, glBindBuffer, glBufferData, glUniform*, the texture
# parameters -- and a build whose file stops here draws nothing until they are added. They are
# added from the device, not from a guess:
#
#   1. install the library with `glslots=1` in the boot-args (see docs/COREANIMATION_GLES.md);
#   2. mondrian_inject.c prints the whole table iOS's GLES builds: "mondrian-gl: slot 0x0030
#      glBindTexture" for every entry it can name, "... (not named)" for the rest;
#   3. tools/gpu/mkeagl.py --from-log <log> --write-slots eagl_slots.txt rewrites this file;
#   4. generate eagl_gen.h again and install the library without glslots=1.
#
# The offsets are properties of the build (iPhone X 16.7.16, 20H392). A different userland
# renumbers them: derive this file again rather than editing it by hand.
